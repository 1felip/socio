# Painel

- Server Components por padrão; Server Actions para formulários; rotas `/api` só para webhooks e integrações.
- shadcn/ui + Tailwind. Mobile-first: o dono usa no celular.
- Toda tela tem estados de carregando, vazio e erro.
- Textos em pt-BR, curtos, no tom da skill tom-socio. Dinheiro como `R$ 12,90`.
- Ações de escrita sempre mostram o que será publicado antes do botão Aprovar.
- Rodapé fixo: "Projeto independente, não afiliado ao iFood."
- Se a skill frontend-design estiver instalada, use-a para telas novas.
